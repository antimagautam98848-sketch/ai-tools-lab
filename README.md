# AI Tools Lab

## Project Description

AI Tools Lab is a Python project developed for learning and practicing Git, GitHub, sorting algorithms, and reusable utility functions. The project contains a Bubble Sort implementation and utility functions for palindrome checking, word counting, and Celsius-to-Fahrenheit conversion.

## Features

- Bubble Sort algorithm
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion
- Python utility functions with documentation
- Git and GitHub version control
